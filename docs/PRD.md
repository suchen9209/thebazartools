# 大巴扎助手 (The Bazaar Assistant) - 需求文档

## 1. 项目概述

### 1.1 项目背景
为《The Bazaar》（大巴扎）玩家提供游戏辅助工具，帮助玩家更好地理解游戏机制、优化构筑、提升胜率。

### 1.2 目标用户
- 大巴扎新手玩家（快速上手）
- 进阶玩家（构筑优化）
- 高分段玩家（数据分析）

### 1.3 产品形态
- **Web 应用**：通过浏览器访问，功能完整
- **桌面应用**：基于 Electron，功能与 Web 一致 + 游戏内悬浮窗

---

## 2. 功能需求

### 2.1 核心工具

#### 2.1.1 物品追踪器
| 功能 | 描述 |
|------|------|
| 物品记录 | 记录本局游戏已获得的物品、附魔、技能 |
| 历史查看 | 查看之前对局的物品获取记录 |
| 导出功能 | 导出本局构筑为文本/图片 |

#### 2.1.2 实时对局提示（桌面版悬浮窗）
| 功能 | 描述 |
|------|------|
| 最佳组合提示 | 根据当前物品，推荐可搭配的协同物品 |
| 最佳站位建议 | AI 推荐当前物品的最优摆放位置 |
| 输出曲线 | 按时间轴展示理论伤害/治疗/控制曲线 |

#### 2.1.3 摆放优化器
| 功能 | 描述 |
|------|------|
| 自动优化 | 根据当前物品自动计算最优摆放 |
| 手动调整 | 支持手动拖拽调整，实时计算效果 |
| 保存模板 | 保存常用摆放模板 |

#### 2.1.4 伤害计算器
| 功能 | 描述 |
|------|------|
| 理论输出 | 计算阵容的理论 DPS/HPS |
| 对战模拟 | 模拟与常见构筑的对战结果 |
| 瓶颈分析 | 找出输出/防御的瓶颈 |

#### 2.1.5 转型规划器
| 功能 | 描述 |
|------|------|
| 路线推荐 | 根据当前构筑推荐转型方向 |
| 物品优先级 | 推荐接下来应该获取的物品 |
| 经济规划 | 金币使用建议 |

---

### 2.2 数据库

#### 2.2.1 物品图鉴
| 字段 | 说明 |
|------|------|
| 基础信息 | 名称、图标、尺寸、类别 |
| 效果描述 | 触发条件、效果、CD |
| 品质数据 | 青铜/白银/黄金/钻石各等级数值 |
| 协同标签 | 相关物品、技能 |
| 获取来源 | 商店类型、野怪掉落 |

#### 2.2.2 商店池查询
| 筛选维度 | 选项 |
|----------|------|
| 商店类型 | 武器店/工具店/水系店/食物店/科技店/中立店 |
| 物品尺寸 | 小型/中型/大型 |
| 物品品质 | 青铜/白银/黄金/钻石 |
| 物品类别 | 武器/工具/水系/飞行/食物等 |
| 效果类型 | 加速/减速/充能/冰冻/灼烧/剧毒/护盾 |
| 角色专属 | 全角色/海盗/商人/机器人等 |
| 天数限制 | 第几天开始出现 |

#### 2.2.3 野怪图鉴
| 字段 | 说明 |
|------|------|
| 基础信息 | 名称、图标、难度等级 |
| 技能介绍 | 怪物技能效果 |
| 掉落物品 | 可掉落的卡牌/技能 |
| 应对建议 | 推荐构筑类型 |

#### 2.2.4 技能图鉴
| 分类 | 说明 |
|------|------|
| 角色专属 | 各角色特有技能 |
| 通用技能 | 全角色可获取 |
| 怪物技能 | 击败野怪获得 |

#### 2.2.5 附魔图鉴
| 字段 | 说明 |
|------|------|
| 附魔名称 | 加速/减速/冰冻/灼烧/剧毒/护盾/辉耀/黑曜石 |
| 效果描述 | 具体效果 |
| 适用物品 | 推荐附魔的物品类型 |

---

### 2.3 构筑系统

#### 2.3.1 构筑库
| 功能 | 描述 |
|------|------|
| 保存构筑 | 保存当前物品组合为构筑 |
| 分享构筑 | 生成分享链接/代码 |
| 导入构筑 | 通过代码导入他人构筑 |
| 收藏管理 | 收藏喜欢的构筑 |

#### 2.3.2 构筑分析
| 功能 | 描述 |
|------|------|
| 胜率统计 | 该构筑的历史胜率 |
| 弱点分析 | 识别构筑的弱点 |
| 改进建议 | 提供优化建议 |

#### 2.3.3 热门构筑推荐
| 分类 | 说明 |
|------|------|
| 按角色 | 各角色的热门构筑 |
| 按流派 | 武器流/水系流/毒流/飞行流等 |
| 按天数 | 前期/中期/后期构筑 |

---

### 2.4 战绩系统

#### 2.4.1 对战记录
| 字段 | 说明 |
|------|------|
| 基本信息 | 日期、角色、胜负、胜场数 |
| 构筑快照 | 该局使用的物品组合 |
| 数据统计 | 总伤害、治疗、回合数 |

#### 2.4.2 数据统计
| 统计维度 | 说明 |
|----------|------|
| 整体胜率 | 总胜率、各角色胜率 |
| 流派胜率 | 各流派胜率对比 |
| 趋势分析 | 胜率变化趋势 |

#### 2.4.3 对手分析
| 功能 | 说明 |
|------|------|
| 常见构筑 | 当前段位常见构筑类型 |
| 强势期分析 | 各构筑的强势期 |

---

## 3. 非功能需求

### 3.1 性能要求
- 页面加载时间 < 2s
- 数据库查询 < 200ms
- 悬浮窗响应 < 100ms

### 3.2 兼容性
- Web：Chrome/Firefox/Safari/Edge 最新版
- 桌面：Windows 10+/macOS 10.15+/Linux

### 3.3 数据更新
- 游戏版本更新后 24h 内同步数据
- 支持离线访问已缓存数据
